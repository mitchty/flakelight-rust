* examples/ebpf

Demonstrates using ~binaries~ and custom workspaces and a split between an ebpf only crate, and a static loader binary that embeds the ebpf binary object code. Also shows a nixos integration test to demonstrate runtime validation that everything still works in a nixos vm.

#+begin_src sh
cd examples/ebpf
nix flake check -L
#+end_src
